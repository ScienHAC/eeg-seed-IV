## 📊 **ACTUAL DATA STRUCTURE USED**

### **Input Data Format:**
```
Each CSV file (e.g., de_LDS1.csv):
- Rows: Time points (varies, ~200-400 rows)
- Columns: 310 features (62 channels × 5 frequency bands)
- Values: Differential entropy values (float)
```

### **Label Mapping:**
```python
session_labels = {
    1: [1,2,3,0,2,0,0,1,0,1,2,1,1,1,2,3,2,2,3,3,0,3,0,3],
    2: [2,1,3,0,0,2,0,2,3,3,2,3,2,0,1,1,2,1,0,3,0,1,3,1], 
    3: [1,2,2,1,3,3,3,1,1,2,1,0,2,3,3,0,2,3,0,0,2,0,1,0]
}
# 0=Neutral, 1=Sad, 2=Fear, 3=Happy
```
